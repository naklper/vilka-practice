# Вилка

Сервис поиска ресторанов и бронирования столиков.

## О проекте

"Вилка" - сайт, где пользователь может найти ресторан, посмотреть меню с ценами
и забронировать столик на нужную дату и время. Бронь привязывается к аккаунту:
её можно посмотреть в личном списке и отменить. Администратор добавляет
рестораны и блюда, а также управляет бронями через админку.

## Стек

- Python 3.14
- Django 6.1
- SQLite
- HTML, CSS, минимальный JavaScript

## Установка и запуск

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/

## Аналитическая часть

### Аудитория

Сайт рассчитан на широкую аудиторию: студенты, пары, семьи, офисные
работники - все, кто планирует поход в ресторан и хочет заранее занять
столик. Основное: выбрать заведение, посмотреть меню и цены,
забронировать стол на вечер.

### Проблема

Сейчас бронирование чаще всего происходит по телефону или через форму
на сайте ресторана, после которой менеджер перезванивает. Это неудобно:
нужно ждать ответа и звонить в рабочее время, а информация о меню и ценах
разбросана по разным источникам. "Вилка" собирает меню, цены и бронь
в одном месте и позволяет забронировать стол без звонка.
